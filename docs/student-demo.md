# Explore the 2024 field studies

Open the [field studies](https://ehartye.github.io/frc-2024-poc/) and select a rehearsal.

- [Field lab](https://ehartye.github.io/frc-2024-poc/field-lab.html#rehearsal) follows three robots on each alliance through a match.
- [Ground relay](https://ehartye.github.io/frc-2024-poc/ground-relay.html) follows Blue 3 and Blue 2 on the same clock as their four peers.
- [Centered entry](https://ehartye.github.io/frc-2024-poc/ground-contact.html) compares contact and release conditions.
- [Off-center entry](https://ehartye.github.io/frc-2024-poc/passive-entry.html) shows the machined R17 carrier as one isolated solid. Select a lateral error and receiver condition to see where each NOTE ends up.

The R7 and R9 whole-robot attachment review found separate wheel/hub pairs and intake motor/plate pairs. These revisions and the historical orbit exhibits have been withdrawn from the student site. [Historical findings](../experiments/passive-entry/showcase-attachments.md)
